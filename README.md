## About

**Unexpected Roles** is a Host-Only mod for **Among Us** focused on custom
roles, gameplay mechanics, and additional features.

The project is based on **Endless Host Roles (EHR)** by Gurge44 and its
contributors, and has been modified and developed into an independent project.

> This project is not affiliated with, endorsed by, or sponsored by Innersloth LLC.

---

## Features

- 🎭 Custom roles
- ⚙️ Configurable gameplay mechanics
- 🏠 Host-Only functionality
- 🛠️ Custom game systems
- 🔧 Extensive configuration
- 🚀 Continuous development

More features will be added as development continues.

## Installation

### Requirements

- Among Us
- BepInEx 6
- A compatible version of Unexpected Roles

### Installation

1. Install **BepInEx 6** for Among Us.
2. Download the latest version of **Unexpected Roles**.
3. Extract the mod files into your Among Us installation directory.
4. Start Among Us.
5. Check the BepInEx console/log to verify that Unexpected Roles loaded
   successfully.
